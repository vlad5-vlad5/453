# Установка Blender + экспортёра i3d для FS19

Пошагово, с граблями, на которые все наступают.

---

## Шаг 1. Blender — версия имеет значение

**Ставьте Blender 4.2 LTS или 4.3.** Не «последний».

Экспортёры i3d всегда отстают от Blender на несколько версий. На самом свежем
Blender аддон устанавливается, но **панель экспорта не появляется** — это самая
частая жалоба на форуме GDN, и лечится она откатом Blender на 4.3
[[GDN]](https://gdn.giants-software.com/thread.php?categoryId=8&threadId=10222).

Скачать конкретную версию: **blender.org → Download → Previous Versions**
(или `https://download.blender.org/release/`, папка `Blender4.2`).

Устанавливайте **от имени администратора** — иначе не пропишутся ключи реестра.

Несколько версий Blender спокойно живут рядом, так что если у вас уже стоит
свежий — просто поставьте 4.2 дополнительно в отдельную папку.

## Шаг 2. Экспортёр — какой из двух

| | Официальный GIANTS | StjerneIdioten (сообщество) |
|---|---|---|
| Откуда | GDN → Downloads (нужна регистрация) | [GitHub](https://github.com/StjerneIdioten/I3D-Blender-Addon), без регистрации |
| Обновления | редко, с задержкой | активно, релиз под каждую версию Blender |
| Установка | инсталлятор, часто ставится криво | обычный zip-аддон |
| **Рекомендация** | | ✅ **берите этот** |

Официальный ставится через .exe-инсталлятор, который регулярно портит установку —
на GDN стандартный совет: жать в инсталляторе «Extract files», а потом ставить
полученный zip вручную через Blender
[[GDN]](https://gdn.giants-software.com/thread.php?categoryId=8&threadId=6536).
С версией от сообщества этой возни нет.

### Установка StjerneIdioten I3D Exporter

1. Откройте страницу **Releases** репозитория.
2. Найдите релиз **под вашу версию Blender** (в описании релиза указано, для какой
   версии он собран — под 4.2/4.3 свои сборки, они лежат и на старых страницах
   релизов, листайте).
3. Разверните **Assets** и скачайте файл **`i3d_exporter.zip`**.
   Скачивайте именно его, а не «Source code (zip)» — это разные вещи.
4. Положите zip в постоянное место (например `Документы\Blender\addons\`),
   не в Загрузки — Blender к нему потом обращается.
5. Blender → `Edit → Preferences → Add-ons → Install…` (в 4.2+ кнопка спрятана
   под стрелочкой ▾ справа сверху → `Install from Disk`).
6. Выберите скачанный `i3d_exporter.zip`.
7. В списке аддонов включите галочку у **«Unofficial GIANTS I3D Exporter Tools»**.
   Если не находится — переключите фильтр категории на **Community**.
8. Разверните аддон и в поле **FS Data Folder** укажите папку `data` игры:
   - Steam: `C:\Program Files (x86)\Steam\steamapps\common\Farming Simulator 19\data\`
   - Диск/Giants: `C:\Program Files (x86)\Farming Simulator 19\data\`
9. Внизу слева меню (три полоски ☰) → **Save Preferences**.

**Не распаковывайте zip руками** в папку addons — аддону важно точное имя папки,
установка через кнопку делает это правильно.

## Шаг 3. Проверка, что всё встало

1. В окне 3D Viewport нажмите **`N`** — справа выедет боковая панель.
2. Там должна появиться вкладка **GIANTS I3D**.

Если вкладки нет — версия экспортёра не подходит к вашему Blender. Ставьте
Blender 4.2/4.3 и релиз экспортёра под него.

Ещё полезно открыть `Window → Toggle System Console` — туда падают ошибки
экспорта и вывод скриптов.

---

## Шаг 4. Сборка мопеда

1. `File → New → General` (чистая сцена — скрипт стирает всё содержимое!).
2. Вкладка **Scripting** сверху.
3. **Open** → выбрать `tools/blender_build_alpha.py` из этого репозитория.
4. **▶ Run Script** (или `Alt + P`).

В Outliner появится дерево `alphaMoped → bodyLean / wheels / player`.
В системной консоли скрипт напечатает ожидаемые пути узлов (`0>0|13|2` и т.д.).

Скрипт **специально назначает материал каждому мешу** — экспортёр ругается и
пропускает объекты без материалов.

---

## Шаг 5. Экспорт

1. Сохраните .blend файл (некоторые режимы экспорта требуют сохранённый проект).
2. Выделите корневой объект **`alphaMoped`**.
3. Боковая панель `N` → вкладка **GIANTS I3D**:
   - режим экспорта: **Selected Objects** (или Everything — в сцене только мопед);
   - путь: папка `FS19_AlphaMoped/`, имя `alphaMoped.i3d`.
4. Нажать **Export**.

Рядом с `alphaMoped.i3d` появится `alphaMoped.i3d.shapes` — **это часть модели**,
её тоже кладём в мод, без неё ничего не загрузится.

---

## Шаг 6. Сверка узлов

Откройте `alphaMoped.i3d` в **GIANTS Editor** и сверьте порядок узлов в дереве
со списком `<i3dMappings>` в `alphaMoped.xml`. Blender при экспорте может
отсортировать детей иначе, чем они создавались — тогда просто поправьте цифры
в XML (`0>0|13|2` и подобные).

Затем:

```bash
./build.sh FS19_AlphaMoped
```

и архив из `build/` — в `Документы\My Games\FarmingSimulator2019\mods\`.

---

## Если что-то пошло не так

| Симптом | Причина |
|---|---|
| Нет вкладки GIANTS I3D в панели `N` | Версия Blender новее, чем поддерживает экспортёр |
| Аддон не виден в списке | Не включён фильтр **Community** |
| «Object has no material» | Меш без материала — экспортёр его пропустит |
| Мод не грузится, в log.txt «Failed to load i3d» | Забыли положить `.i3d.shapes` рядом с `.i3d` |
| Мопед в игре едет задом наперёд | Поменяйте `FWD` в начале `blender_build_alpha.py` |
| Кренит наружу поворота | Поменяйте знак `targetAngle` в `AlphaMopedLean.lua` |
