🏳️ Добавить страну в M3U-плейлист

Загрузите ваш .m3u файл — название страны будет дописано рядом с именем каждого канала: «BBC One (Великобритания)». Работает офлайн, файлы никуда не отправляются. EPG не ломается — привязка идёт по tvg-id, он не меняется.
Как будет выглядеть (первые каналы): 
— загрузите файл —
Или вставьте текст плейлиста:
Страна определяется по атрибуту tvg-country, затем по коду в конце tvg-id (формат iptv-org, например .ru), затем по названию группы (group-title). Скрипт идемпотентен: повторная обработка не портит результат.
