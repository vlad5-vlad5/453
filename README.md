# Моды для Farming Simulator 19

Два мода в одном репозитории плюс инструменты сборки.

| Мод | Что делает | Готовность |
|---|---|---|
| `FS19_FarmHelper` | HUD с балансом, временем, погодой и данными поля | ✅ готов к игре |
| `FS19_AlphaMoped` | Мопед «Альфа 110» — техника для магазина | ⚠️ нужен экспорт `.i3d` (см. ниже) |

```bash
./build.sh                  # собрать оба мода в build/
./build.sh FS19_AlphaMoped  # собрать один
./build.sh install          # собрать и скинуть в папку модов игры
```

---

# 1. FS19_FarmHelper — HUD-помощник

Панель в углу экрана: баланс фермы, игровое время и день, погода с температурой,
номер и площадь поля, на котором вы стоите.

**Клавиша:** `Right Ctrl + H` (переназначается в *Настройки → Управление*).

```
FS19_FarmHelper/
├── modDesc.xml                  # манифест (descVersion="53" = FS19)
├── icon_FarmHelper.dds
├── scripts/
│   ├── FarmHelper.lua           # loadMap / update / draw
│   └── FarmHelperSettings.lua   # настройки в modSettings
└── translations/                # ru + en
```

Настройки сохраняются в
`Документы\My Games\FarmingSimulator2019\modSettings\FS19_FarmHelper.xml`
(позиция панели, размер шрифта, какие блоки показывать).

# 2. FS19_AlphaMoped — мопед «Альфа 110»

Покупаемая техника: 110 см³, 7 л.с., 65 км/ч, бак 4 л, цена 1900.
Появляется в магазине в категории **Автомобили**.

```
FS19_AlphaMoped/
├── modDesc.xml                  # свой vehicleType alphaMoped (parent="car")
├── alphaMoped.xml               # вся конфигурация техники
├── store_alphaMoped.dds         # картинка в магазине
├── icon_alphaMoped.dds
├── scripts/
│   └── AlphaMopedLean.lua       # специализация: наклон в поворотах
├── translations/
└── alphaMoped.i3d               # ← ЕГО НУЖНО ЭКСПОРТИРОВАТЬ (см. ниже)
```

### Что уже сделано

- **Физика.** FS19 не умеет держать равновесие на двух колёсах, поэтому
  используется приём всех рабочих мото-модов: **4 физических колеса**, сдвинутых
  к осевой линии на ±55 мм. Видимых колёс два — меши висят на `driveNode` левых
  колёс, правые невидимые. Привод на заднее колесо.
- **Мотор.** `torqueScale="0.09"`, 8500 об/мин, 4 передачи. По асфальту едет
  бодро, по пашне заметно вязнет — как настоящая Альфа.
- **Свет.** Фара (ближний/дальний), стоп-сигнал, четыре поворотника.
- **Наклон в поворотах.** Специализация `AlphaMopedLean` кренит корпус до 22°
  в зависимости от угла руля и скорости. Эффект чисто визуальный — на физику и
  мультиплеер не влияет. Настраивается прямо в XML:
  ```xml
  <alphaMopedLean node="bodyLean" maxAngle="22" speedFactor="0.055" smoothing="3.5"/>
  ```
- **Прочее:** расход топлива, износ, мойка, выхлоп, звук, круиз-контроль.

### Чего не хватает: 3D-модель

`.i3d` — это единственное, что нельзя сгенерировать текстом: геометрия лежит в
бинарном `.i3d.shapes`. Поэтому в репозитории есть **генератор модели для Blender**:

```bash
blender --background --python tools/blender_build_alpha.py
# или в Blender: вкладка Scripting -> Open -> Run Script
```

Скрипт строит low-poly Альфу в реальных пропорциях (база 1220 мм, колесо R335,
седло 770 мм) с иерархией узлов, **точно соответствующей** блоку `<i3dMappings>`
в `alphaMoped.xml`: рама, бак, седло, двигатель, глушитель, багажник, крылья,
вилка, руль, фара, поворотники, четыре колеса, точки посадки и две камеры.

Дальше:

1. `File → Export → GIANTS I3D` → сохранить как `FS19_AlphaMoped/alphaMoped.i3d`
   (нужен [GIANTS I3D Exporter для Blender](https://gdn.giants-software.com/downloads.php)).
2. Открыть `.i3d` в **GIANTS Editor** и сверить индексы узлов с `<i3dMappings>` —
   скрипт печатает ожидаемые пути (`0>0|13|2` и т.д.) в конце работы.
   Порядок детей при экспорте может отличаться, тогда поправьте пути в XML.
3. В GIANTS Editor пометить объекты как *Rigid Body / Collision* там, где нужно
   (корневой компонент — Dynamic, колёса физику получают из XML).
4. `./build.sh FS19_AlphaMoped` → архив в `build/`.

Если в игре мопед едет задом наперёд — поменяйте `FWD` в начале скрипта на
противоположный знак и переэкспортируйте. Если кренит наружу поворота — поменяйте
знак у `targetAngle` в `AlphaMopedLean.lua`.

Разумеется, вместо генератора можно взять любую готовую модель мопеда
(Sketchfab, Meshy AI, собственный Blender-проект) — главное назвать узлы так же.

## Разработка

| Задача | Инструмент |
|---|---|
| Скрипты Lua | GIANTS Studio (с отладчиком) или VS Code |
| Модели, i3d, коллизии | GIANTS Editor + Blender с GIANTS I3D Exporter |
| Документация API | GDN → Scripting Documentation FS19 |
| Текстуры/иконки | `tools/make_textures.py` (PNG → DDS нужного размера) |

**Аргументы запуска игры** (свойства ярлыка): `-cheats -autoStartSavegameId 1` —
сразу в сохранение №1 плюс консоль разработчика по `~`.

**Lua в FS19 не перезагружается на лету** — после правки скрипта перезапускайте игру.

**Первое место при любой ошибке** — `Документы\My Games\FarmingSimulator2019\log.txt`.
Туда же попадают все `print()` из модов.

**Отладка без сборки zip:** положите распакованную папку мода прямо в `mods\` —
игра подхватывает и папки тоже.
