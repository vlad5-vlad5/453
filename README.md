# 📺 Мировое ТВ — IPTV-плеер для телевизора

Веб-плеер IPTV-плейлистов (M3U/M3U8) с крупным интерфейсом под пульт и управлением
клавиатурой. **Рядом с названием каждого канала показывается название и флаг страны** —
и в списке каналов, и в оверлее при перемотке каналов.

## Как запустить

```bash
npm install
npm run dev      # разработка
npm run build    # production-сборка в dist/
```

## 📺 Установка на телевизор

Сборка уже опубликована в ветке `gh-pages`. Нужно один раз включить GitHub Pages:
открыть **Settings → Pages → Source: Deploy from a branch → `gh-pages` / root → Save**.
Через минуту плеер будет доступен по адресу:

**https://vlad5-vlad5.github.io/453/**

Эту ссылку открывают в браузере телевизора (Samsung Tizen, LG webOS, Android/Google TV).
После изменений в коде обновить сайт: `./scripts/deploy-pages.sh`.


## Загрузка плейлиста

Кнопка **«📋 Плейлист»** внизу справа:

- **URL** — ссылка на ваш `.m3u` / `.m3u8` (сохраняется в браузере);
- **Файл** — выбор локального M3U-файла (например, `iptv_world_public_legal_with_epg.m3u`);
- для проверки есть встроенный пример: `public/sample.m3u`.

## Откуда берётся страна канала

1. атрибут `tvg-country` (или `country`) в строке `#EXTINF`;
2. если его нет — определение по `group-title` («Россия», «Германия», «Ukraine»…);
3. иначе показывается «страна не указана».

Названия стран выводятся **на русском** с флагом (🇺🇦 Украина, 🇩🇪 Германия…),
в справочнике ~150 стран (`src/countries.ts`).

## Управление с пульта / клавиатуры (TV)

| Клавиша | Действие |
|---|---|
| `↑` / `↓` | перемотка каналов (во время просмотра) / листание списка |
| `←` / `→` | предыдущий / следующий канал |
| `PageUp` / `PageDown` | Канал − / Канал + |
| `Enter` / `OK` / `Пробел` | смотреть выбранный канал |
| `Esc` / `Backspace` | назад (остановить просмотр, вернуться к списку) |
| `M` | включить/выключить звук |

При переключении канала внизу слева на 4 секунды появляется оверлей:
**номер канала, название, страна с флагом и группа**.

## Стек

React 18 + TypeScript + Vite, воспроизведение HLS через `hls.js`.
