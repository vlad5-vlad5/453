# Как выпускать обновления

Единственный переключатель — файл `release.json`:

```json
{ "release": "2026-12-26" }
```

## Порядок действий

1. Вносите правки в `index.html` / `style.css` / `script.js` и пушите в `main`
   когда угодно. **Гости ничего не заметят** — они видят кэшированную версию.
2. Проверьте сами: откройте сайт, посмотрите глазами.
3. Когда готовы выпустить — поменяйте номер в `release.json`, например на
   `2027-01-01`, и запушьте только этот файл.
4. Все гости получат обновление в безопасный момент:
   - на паузе,
   - когда трек закончился,
   - когда вернулись в приложение.
   Песня не обрывается: позиция сохраняется и восстанавливается.

## Что видит владелец

На сайте с `?admin=1` внизу появляется плашка:

> На сайте выпуск «2027-01-01», у вас «2026-12-26» — скачан и готов к применению.

Если плашки нет — всё совпадает.

## Чего НЕ делать

- Не меняйте `release.json` вместе с кодом: правки уедут гостям мгновенно,
  до того как вы их проверите.
- Номер можно только увеличивать. Откат `release.json` назад не откатывает
  гостей — у них останется выпущенная версия.
- Не трогайте `CACHE_VERSION` в `sw.js` без необходимости: версии оболочки
  теперь считаются от `release.json`.
